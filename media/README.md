# Media contract

The labelled reference is committed. Policy renders stay ignored until a final run is
packaged with its evaluation evidence.

- `reference-kinematic.mp4`: clearly watermarked reference trajectory; never described
  as policy output.
- `raw/stock/`: uncut fixed-camera stock SONIC render.
- `raw/finetuned/`: uncut identical-camera selected-checkpoint render.
- `hero-before-after.mp4`: roughly 30-second target/before/after comparison built only
  after both raw policy renders and frozen metrics exist.
- `video-manifest.json`: hashes the reference, every matched uncut source render, the
  final-test comparison report, and the edited output.

The final edit keeps both feet visible, uses matched timing/camera, labels every panel,
and does not cut around a fall or reset.
